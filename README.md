# devarshbagla.github.io

Personal site for [Devarsh Bagla](https://devarshbagla.github.io).

Plain HTML, CSS, and vanilla JavaScript ES modules. No framework, no build step, no bundler, no npm. Served directly from `main` via GitHub Pages.

## Local development

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000).

## Structure

```
index.html
css/          tokens, base, layout, components
js/           main + theme modules
assets/       static media (empty for now)
.nojekyll     required so GitHub Pages serves underscore paths
```
